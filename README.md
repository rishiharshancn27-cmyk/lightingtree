# Recursive Turtle Tree

A small Python project that draws a branching tree using the built-in `turtle` graphics module.

## Requirements

- Python 3
- A desktop environment that supports Tkinter (used by Python's `turtle` module)

No third-party Python packages are required.

## Run

```bash
python tree.py
```

On some systems, use `python3 tree.py` instead.

The drawing opens in a separate window. Close the window to exit.

## Customize

In `tree.py`, change the starting length in `draw_tree(pen, 100)` or adjust the colors, branch angle, and branch-length multiplier in `draw_tree`.
